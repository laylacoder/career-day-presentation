The Fields

Data Engineering

Data engineers build the infrastructure that moves, cleans, and organizes data so it can be trusted and used. Think of it like building the plumbing system for information — without it, nothing downstream works. If Spotify knows your taste, if a voter outreach app knows who to call next, a data engineer made that possible.

Python SQL Data Pipelines ETL Cloud Infra

Software Engineering

Software engineers design and build the apps, websites, and systems people interact with every day. From mobile apps to backend APIs to games — if users touch it, a software engineer built it. It’s about taking a problem and writing code that solves it reliably at scale.

How to Build Your Career Path
1
Right Now (8th – 9th Grade)

Start with the basics — for free

Learn Python on Codecademy (free). Practice logic with Khan Academy. No experience needed — just curiosity and internet access.

2
High School

Take CS classes + build something

Take any computer science or coding class offered. Build small projects (a website, a script, a game). GitHub is your portfolio — start one early.

3
College or Bootcamp

CS, Data Science, or a coding bootcamp

A 4-year CS or Data Science degree is one path. Coding bootcamps (3–6 months) are another. What matters most: real skills + real projects.

4
First Job

Junior / Associate Engineer

Apply for internships in high school and college. Your first job won’t be perfect — it’s where you learn fastest. Stay curious, ask questions, grow.

5
3–10 Years In

Choose your direction

Go deep as a Senior / Staff Engineer (individual contributor), or grow into a tech lead / engineering manager role. Both are great — it’s your choice.

Key Vocab & Free Resources

The words you’ll hear — and where to start learning today

Career Day 2026
Know the Language
Pipeline An automated series of steps that moves and transforms data from one place to another — like an assembly line for information.
SQL A language used to talk to databases. If you want to find, filter, or organize stored data, you write SQL. It’s one of the most-used skills in tech.
Python A beginner-friendly programming language used everywhere — data engineering, AI, web apps, automation. The best first language to learn.
API (Application Programming Interface) A way for two systems to talk to each other. When a weather app shows your forecast, it’s using a weather API.
ETL (Extract, Transform, Load) The core pattern in data engineering: pull data from a source, clean it up, then load it somewhere useful.
Algorithm A step-by-step set of instructions to solve a problem. Every piece of software is built on algorithms — from sorting a list to recommending a video.
Git / Version Control A system that tracks every change you make to code, so you can collaborate with a team and never lose your work. GitHub is built on Git.
Cloud Servers and storage you access over the internet instead of owning them yourself. AWS, Google Cloud, and Azure are the big three providers.

Remember This

  • You don’t need a fancy school to start — curiosity and internet access are enough.
  • Python + SQL are the two most important languages in data. Start with Python.
  • Communication matters — tech jobs involve a lot of writing. Practice it now.
  • Management is a choice, not a requirement. Senior individual contributor is an amazing career too.
  • Follow what interests you at each step. Careers rarely go in a straight line — that’s fine.
